# 「我知道你不知道」游戏设计

日期:2026-06-10

## 目标

促进家人互相了解的问答游戏。每轮一位家人当"主角",抽一张关于主角世界的题卡,
其他人先抢答/猜,主角再公布答案。答对的人证明"我懂你",全场没人答对则主角得
"独家秘密"分——"我知道你不知道!"

## 固定角色(4 位)

| id | 名称 | 形象 | 题库方向 |
|----|------|------|----------|
| dad | 爸爸 | 👨‍💻 | 程序员/AI 工具日常、程序员梗、个人喜好 |
| mom | 妈妈 | 🛍️ | 商场工作日常(早晚班、盘点、对讲机、节假日最忙)、36 岁女性休闲(短剧、直播间)、个人喜好 |
| bigSis | 大女儿 | 🎤 | 邓紫棋粉丝知识、2025-26 青少年流行梗、小升初话题、个人喜好 |
| lilSis | 小妹妹 | 🎀 | 一年级校园生活、低龄流行 IP(小马宝莉卡、chiikawa、蛋仔派对等)、个人喜好 |

## 题卡两种类型

- **trivia(知识题)**:有参考答案,来自主角的"世界"(如"邓紫棋的本名是什么?")。
  其他人答,翻卡看参考答案,主角有最终裁定权(答案可能跟自家情况不同)。
- **personal(走心题)**:无固定答案,以主角口吻提问(如"我最近最烦恼的事是什么?")。
  其他人先猜,主角公布真实答案,主角判定谁猜对。

每张卡带 emoji 配图 + 类型徽章 + 主角色横幅,纯前端无图片资源。

## 流程(沿用 stages 模式)

intro → setup → playing → reveal(同 playing 页内翻转) → result

- **setup**:勾选今天在场的角色(≥2);选每人题数(3/5/8)。
- **playing**:按角色轮转出题(洗牌)。卡片正面=题目,点"翻开答案"显示参考答案
  (personal 题显示"听主角公布答案")。下方列出其他在场角色的头像 chip,
  点选谁答对了 → "下一题"。无人答对时自动给主角 +1 独家分,弹"我知道你不知道!"反馈。
- **result**:两个榜单——"最懂家人榜"(答对数)与"最神秘榜"(独家分),
  配称号(全家百事通 / 最神秘家人等)。可再来一轮(题目不重复,题库耗尽时重置)。

## 数据模型

```ts
type RoleId = 'dad' | 'mom' | 'bigSis' | 'lilSis'
interface KnowQuestion {
  role: RoleId
  kind: 'trivia' | 'personal'
  text: string      // 题面
  answer?: string   // trivia 参考答案
  emoji: string     // 卡面配图
}
```

题库每角色 ≥100 题,带 `tag` 主题标签,不只盯职业/单一爱好,按年龄段全面覆盖:

- 爸爸:80 后青春回忆(小霸王/魂斗罗秘籍/灌篮高手/周杰伦/CS/QQ 等级)、
  中年男人兴趣(钓鱼/台球/数码 EDC)、程序员世界、走心题
- 妈妈:90 后少女回忆(还珠格格/F4/超女 2005/QQ 空间非主流/校门口零食)、
  当下女性热点(短剧/直播间/养生/MBTI)、商场工作日常、走心题
- 姐姐:邓紫棋、2025-26 热梗(全面)、手游(蛋仔/光遇)、谷子圈黑话、
  小马宝莉卡、文具桌搭、小升初校园、走心题
- 妹妹:动画细节(汪汪队/奶龙/巴啦啦)、儿歌洗脑曲(孤勇者)、玩具
  (捏捏/咕卡/电话手表碰一碰)、一年级校园(拼音/跳绳/小红花)、走心题

数据按角色分文件:`data/dad.ts` / `data/mom.ts` / `data/big-sis.ts` /
`data/lil-sis.ts`,由 `data/know-questions.ts` 聚合,共享 `data/builders.ts`。

## 技术

- 目录 `src/games/know-you/`,完全复用 story 游戏的组件风格(Card/Button/cn)。
- 状态:useReducer,单文件 shell `KnowYouGame.tsx` + stages + data + utils。
- App.tsx 九宫格替换一个 "soon" 占位为新游戏入口。
- 无后端、无存储(仅 introSeen localStorage)。
