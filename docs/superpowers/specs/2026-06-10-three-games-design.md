# 三个新游戏设计：你画我猜 / 猜价格 / 两真一假

日期：2026-06-10
状态：已实现

## 背景与选型

现有 4 个游戏（谁是卧底、你来比划、编故事、我知道你不知道）偏语言/知识型。本次新增三个，目标：

- **猜价格**：补「妈妈优势局」——妈妈在商场工作，对物价最有感觉；妹妹零门槛瞎猜也能玩。
- **你画我猜**：点亮首页占位，7 岁妹妹最友好的玩法（不识字不影响画）。
- **两真一假**：临场吹牛拆穿类，与「我知道你不知道」的题库问答互补，内容成本低、笑点密集。

备选未做：歌词猜歌（版权灰区）、看图猜成语（配图成本高）、记忆翻牌/反应测试（缺全家围观互动感）。

## 通用架构

沿用既有模式：每游戏一个目录（`src/games/<id>/`），`useReducer` 状态机 + `stages/` 阶段组件 + `data/` 题库 + `types.ts`。首页 `App.tsx` 注册路由卡片。家人四角色复用 know-you 的 emoji 画像（👨‍💻🛍️🎤🎀）。

## 你画我猜（draw）

- 流程：intro → setup（难度多选 + 时长 60/90/120s）→ preview（画手私密看词，可换词）→ drawing（触屏画板 + 倒计时）→ roundEnd（揭晓答案）→ result（战绩列表）。
- 画板 `DrawCanvas`：pointer events + devicePixelRatio 适配，5 色画笔、橡皮、撤销、清空；笔画存数组重绘。
- 词在 drawing 阶段默认隐藏，画手「按住看词」浮层偷看；类别提示对猜的人常驻显示。
- 词库 246 条（easy 90 / medium 95 / hard 61），联网调研：经典词库 + 2026 小学生流行（小马宝莉、蛋仔、拆卡）+ 可画的成语与热词（内卷、躺平、显眼包）。

## 猜价格（price）

- 流程：intro → setup（在场家人 + 商品类型多选 + 5/8/12 题）→ guessing（按人轮流输入报价，已出价者显示 🤐 不露数字）→ reveal（真实价 + 趣味出处 + 按误差排名）→ result（购物达人榜）。
- 计分：误差最小者 +1（可并列）；误差 ≤10% 算「神价」+2。
- 题库 130 条联网调研真实市价（2025-2026），八类覆盖全家世界，价格梯度 0.5 元（一度电）到 7 亿（C919），note 附出处/冷知识。

## 两真一假（truth-lie）

- 流程：intro → setup（在场家人 + 每人当几次主角）→ tell（主角看话题提示卡说三件事，可换卡/自由发挥）→ vote（其他人各选 1/2/3 投假话）→ reveal（主角公布答案 + 本轮得分）→ result（总分榜）。
- 计分：投中假话 +1；主角每骗过一人 +1。`scoreRound`/`totalScores` 纯函数集中在 types.ts。
- 话题提示卡 61 条，六类（童年回忆/学校与工作/吃吃喝喝/玩乐爱好/糗事现场/小心思），全年龄可答。
