# 课间大乱斗 /《觉醒者》— 系统设计 bible

> 世界观/文案见 `battle-school-lore.md`；本文件是**系统/数据/玩法/留存**的总设计，落地时对照执行。
> 引擎：Phaser 3 全接管（物理/碰撞/输入/AI/波次/Boss/相机/生物群系/juice），React 只做薄 UI（经类型化事件桥）。

## 1. 人物数据模型（复用 profiles 用户表，**不建关系表**）

```
profiles（云端用户表，已存在）扩字段：
  id · name · emoji · sync_code(NULL = NPC，进不来)
  + role   : family(可登录玩家) | classmate(同学,无码) | teacher(老师,无码)
  + gender : male | female              → 按性别选精灵 + 配名字
  + class_id : 班级id                    → 唯一的「关系」分组键
  + meta jsonb : 老师专用(subject / hp / taunts / winLine / boss机制类型)
```

- **关系 = 共享 `class_id`**。某玩家的同学/老师 = 同 `class_id` 的 classmate/teacher 行。一个字段搞定，**不需要关系表**（每人只属一个班=一对多）。将来真出现多对多（一师教多班）再加 junction。
- **难度 band（low/high…）由 class_id 对应年级派生**，驱动抽题。
- **升年级/小升初/分班 → 关系重新维护**：名册不是静态的。给孩子指向**新 class_id** + 维护那个新班的同学/老师行；旧班数据保留。维护工作流：建新班 → 填同学/老师 → 把孩子指过去。
- **「以后都可能是玩家」**：classmate 行 + 发个 `sync_code` = 立即升级为真玩家，战绩可接续。这是关系表给不了的平滑升级。
- 无码者（classmate/teacher）按 role 过滤出**登录/切换列表**，只当游戏 NPC。维护集中在管理员面板，云端单一真源、各设备同步。
- 现状：名册暂在 `src/games/_battle/roster.ts` 硬编码（low=闫顺儿+2师，high=闫一依+4师）。迁移路径：`rosterFor` 改读云端 profiles（硬编码兜底）。

## 2. 战斗核心循环

- **普攻 = 真理巴掌**（单招，含暴击版，动作大有演出），免费连点，moment-to-moment 的爽。
- **技能 kit 分层**：
  - 免费快速操作技能：逻辑回旋踢(位移挑空) / 鄙视唾沫(击退) / 嘴遁(眩晕) —— 耗能量+冷却，**不答题**，负责走位操作。
  - 答题门控强力技能 + 学霸大招 + Boss：**答题驱动**，题**按科目对应**（数学技能→数学题，各科 Boss→各科题）。
- **答题融入日常战斗**：靠近敌人 → 轻量飘浮快题（不卡片、答完即飘走）→ 答对触发强化暴击招式（秒杀）；答错/不答 → 只能普通磨且可能挨揍。题要**多、有深度分层（杂兵一步速答/Boss多步思考）、连对连击引导多答**。
- **连招/组合**（参考三国战纪/恐龙快打/Streets of Rage）：普攻连段(三下击飞)、挑空 juggle、技能组合(定身→必杀)、**答题嵌进连招升级「必杀连段」**(伤害翻倍+满屏炫光)。
- **跳跃有用**：可躲地面攻击 + 起跳短无敌帧；落点/距离/时机都算数，给操作深度（但不硬核，全家能玩）。

## 3. Boss 体系（可扩展）

- Boss = `role=teacher` 行，`meta` 带 subject / hp / taunts / winLine / **机制类型**。
- **数量随年级扩**：low 2 科 → high 4 科 → 可继续加（英/科/体/美/音…）。
- **机制多样**：基础(答题掉血) / 护盾(连答2题破盾) / 多阶段(血段切招) / 限时抢答 / 双老师联手。
- **血厚 + 多题**：一场 Boss 连答好几题才倒，难度与题量一起上。
- **特殊/终局 Boss**：校长(超级 Boss)、**虚空·愚昧本体**(终局，接 lore)。

## 4. 成长留存（云端按玩家，接现有 learn/progress/badges）

- **觉醒者等级(XP)** 🌟主线：答对/解救/通关攒脑力值 → 升级 → 解锁技能/招式/场景。称号：觉醒新星→思考者→学神→脑力领主→…
- **积分/知识币**：每局赚，换皮肤/招式/宠物 —— "再来一局"的理由。
- **战斗徽章**（复用现有勋章系统）：首通 / 连对20 / 全科满分 / 无伤通关 / 解救满100。
- **关卡不止 4 关**（反"几关就结束"）：无尽模式(刷分) + 每日一战(新题/新Boss) + 更多校区(地图扩张，叙事=虚空蔓延)。
- **第二期**：错题本回炉(答错→复仇关→答对双倍XP，学习闭环) + 家庭排行榜(等级/连对，兄弟姐妹竞争)。

## 6. 操作

- **桌面**：WASD/方向 移动，W/↑/Space 跳，J 普攻，K 技能，L 切换技能。
- **手机**：左**虚拟摇杆**(按下生成、拇指跟手、归一化方向、回中、支持斜向) + 右侧**大号触屏技能钮**(普攻/跳/大招/切换，按下反馈、贴边易够)。

## 7. 老师主动攻击（Boss 不只出题，会「管教」你）

老师不再只是站桩出题——会用**真实校园管教动作**主动揍你。目的：①给跳/走/挣脱的**操作性**；②让 Boss 真有威胁；③主题化又搞笑（中二+搞笑）。
**公平铁律**：每招必带 telegraph（≥0.5s 视觉+音效起手 tell），给反应窗口；难度靠组合与频率，**绝不瞬秒**。全家向，杂兵班的老师招少且慢，高年级老师招多且快。

通用招池（老师从中抽 2~3 招 + 1 招本科目特色）：

| 招式 | 取材 | 机制 | 躲法 | 演出 |
|---|---|---|---|---|
| 拍桌子 | 拍桌震场 | 地面冲击波沿地板扩散 | **跳** | 举手→桌子高亮→DONG+震屏 |
| 粉笔头/板擦飞 | 扔粉笔 | 快速水平飞弹 | 走位/跳 | 抬手瞄准线→嗖 |
| 唾沫横飞 | 讲话喷唾沫 | 身前短锥范围 | 后退拉开 | "讲台三米全是水"锥形 |
| 出来罚站! | 罚站 | 定身 N 秒（不能移动） | **狂点挣脱** | 锁链+聚光灯+挣脱条 |
| 作业山 | 布置作业 | 天降作业砸随机列（AOE） | 走开落点 | 地面阴影预警→书本砸下 |
| 我点名了! | 点名提问 | 强制限时抢答，错/超时=掉血 | 答对 | 飘浮题+倒计时（复用 FloatingQuiz） |
| 没收! | 没收手机 | 临时禁用你一个技能钮 | 打中老师夺回 | 技能钮变灰+"没收"飘字 |
| 眼神杀 | 瞪你 | 站着不动且面对他=短眩 | 保持移动 | 红光锁定线 |
| 拖堂（狂暴） | 拖堂 | 血<30% 进狂暴：攻速↑「这题讲完再下课」 | 速战速决 | 屏幕泛红+BGM 加速 |
| 最差的一届 | 经典口头禅 | 全屏士气 debuff，你伤害短暂↓ | 撑过去 | 黑底台词横幅 |

**节奏 & 与破盾循环合流**：老师在「出题窗口」之间穿插主动招（idle→telegraph→attack→recover，每 2.5~4s 抽一招）。
循环：老师出题(我点名了/护盾题) → 答对破盾 → 近身输出窗口 → 老师重立护盾并恢复主动招；中间一直有拍桌/粉笔小招逼你走位。
数据：Boss `meta` 可选 `moves: string[]`（省略=按 subject/band 取默认池）。

## 8. 地图：固定手工关卡 + 超级玛丽元素（#26/#24 合流）

方向定了：**做固定手工关卡**（像 1-1/1-2 可背可练、精致），而非纯程序生成的"重复汤"。移植超级玛丽元素：

- **上下平台 / 悬空砖块**：跳跃落点，立体战场。
- **坑**：掉下去=掉血+回退（全家向，**不秒死**）。
- **管道**：传送到隐藏房/支线，或纯障碍。
- **问号砖 ❓**：顶出知识币/能量/临时强化（护盾/暴击）。普通砖可顶碎。
- **踩怪**：跳到杂兵头上=踩死/弹起 juggle（呼应"跳跃有用"）。
- **移动平台 / 跳板**、**旗杆/校门终点**（关底=Boss 老师）。
- **隐藏区**：藏知识币/错题彩蛋。
- **伪装陷阱**：看起来正常的平台/砖，突然塌陷或弹刺（之前 #26 的"惊喜坑"并入）。

**手工骨架 + ~1/3 随机层（防背版乏味）**：每关 2/3 是固定手工布局（地形/平台/坑/终点骨架不变，可背可练），**约 1/3 元素每局随机**：
- 杂兵**刷怪点/数量/种类**随机（这批是男同学还是女同学、几只）。
- 问号砖**内容**随机（这块出金币还是能量还是强化）。
- 哪些坑是**真陷阱 vs 安全跳台**随机、伪装陷阱**触发位置**随机（看着一样，这局坑你那块换了）。
- 可选**随机空/掉落道具**点。
固定骨架保证手感与公平（不会随机到过不去），随机层保证"每局不一样"。比例可调（默认 ~33%）。

**与 Roguelite #24 的关系**：固定关卡是"基石单元"；远征模式把这些手工关 + Boss + 抽卡节点串成**分叉流程**——既有手工关精致，又有 roguelite 的不重复。落地顺序：先把固定关卡做扎实（含上面的随机层），再叠远征图层。
