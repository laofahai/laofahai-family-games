## 一、核心设定（一句话能讲清）

宇宙级的力量 **「虚空·愚昧」** 降临，把所有人的大脑「**格式化**」成只会机械服从的**空壳**。
只有你——在最平平无奇的瞬间——**觉醒**了这世界唯一的禁忌力量：**「思考」**。
全校只剩你还"在线"。你脑里的每一份知识都能凝成招式，把空壳**强制重启**、唤回神智。

**机制焊死：**
| 玩法 | 故事里是什么 |
|---|---|
| 一波波同学小怪 | 被格式化的同学空壳，你在**解救**他们 |
| 答对题 / 学霸大招 | **知识共鸣**——唯一能重启空壳的力量，答对=救人，连对=连锁觉醒 |
| Boss（老师） | 被愚昧侵蚀最深、变成中二领主的老师；打赢=解放整间教室 |
| 关卡推进 / 生物群系 | 愚昧从校园向外蔓延：操场→后山森林→荒漠考场→雪原→夜空母舰 |
| 最终 Boss | 源头「虚空·愚昧」本体·绝对沉默之王 |
| 失败 | 你的思维被重新格式化了…（但思考杀不死）再次觉醒！ |

## 四、招式名（答对触发，按连击数升级）

- 答对（普通）：`知识·觉醒斩！`
- 连对 ×2：`连锁思辨·二重奏！`
- 连对 ×3：`无限解·脑速超频！`
- 连对 ×4+：`学神附体·降维打击！`
- 学霸大招（蓄满 / 学习类技能）：`真·终极·脑内核爆——「我 · 思 · 故 · 我 · 在」！！！`
- 群体大招（清波）：`全·知·全·能 · 寰宇格式化反击！`

普攻（随机爆笑招式，动作大、有演出，平时连点可出；答对题则触发其"强化暴击版"）：
- 大耳刮子 →「**真理巴掌**」👋
- 踹一脚 →「**逻辑回旋踢**」🦵
- 喝啐/呸 →「**鄙视唾沫·暴击**」💦
- 毒舌 →「**嘴遁·精神污染**」🗯️
- 其他可加：`常识铁拳` / `这题我会·拳！` / `课本砸脸`

**核心战斗循环（owner 2026-06-14 拍）**：普攻负责爽+搞笑；答题驱动强力输出。靠近敌人冒轻量飘浮快题→答对触发强化爆笑招式（暴击/秒杀）→连对涨连击（招式更花、大招更快、加分勋章）。题要"多、有深度分层、被引导着多答"，但用飘浮快题保证 snappy 不烦（杜绝"一个小怪反复弹卡片"）。

## 五、全部 UI 文案（可直接进游戏）

**开场（StartScreen）**
- 标题：`觉醒者`（副标题小字：课间大乱斗）
- 引子：`全校都被「虚空·愚昧」格式化了，变成只会发呆的空壳。只有你——觉醒者 {playerName}——还在思考。用知识把大家一个个唤醒回来。`
- 开始按钮：`觉醒` / `就绪——开始思考`

**进入关卡（level intro）**
- `第 {n} 关 · {biomeName}｜愚昧已蔓延至此。把这里的人唤醒。`

**遭遇一波小怪（wave）**
- `一群空壳围过来了……（其实他们只是想抄你作业）`
- `{n} 个被格式化的同学。别怕，他们打不准。`

**答题卡片（quiz open）**
- 普通题：`知识共鸣——答对就能重启 TA！`
- Boss 题：`领主的弱点是「正确答案」。一击命中它的逻辑！`

**答对（quiz correct）**
- `💥 {skillName} TA 的眼睛重新亮了——清醒了！`
- 连对追加：`连锁觉醒 ×{combo}！脑子转得停不下来了！`

**答错 / 超时（quiz wrong / timeout）**
- 答错：`啊这——逻辑反噬！愚昧之力趁虚而入，扣点神智。`
- 超时：`想太久，空壳一拳糊脸上了。（下次快点想！）`

**解救一个小怪 / 清空一波**
- `叮——一个空壳重启完成。`
- `这一波全醒了！他们朝你竖大拇指（然后又去发呆了）。`

**打赢 Boss（level clear）**
- `「{bossTitle}」轰然倒地，头顶的虫…啊不，愚昧退散了。整间教室醒了过来！`
- `但你抬头——更深处，还有更大的沉默在凝视着你。`

**通关（victory）**
- `你唤醒了整座学校。「虚空·愚昧」被你一题一题地，问倒了。`
- `（全校师生：我们刚才……经历了什么？）你笑而不语——因为解释太费脑子。`

**失败（lost）**
- `你的思维被重新格式化了……`
- 小字：`但思考是杀不死的。深吸一口气——再次觉醒！`
- 按钮：`重新觉醒`

## 七、写作守则（给后续所有文案）

1. **一本正经地中二**——招式/头衔要"大"，旁白要"严肃"，靠内容的荒诞自己产生笑点，不要自己挠自己痒。
2. **现实戳破**——每段中二后面跟一句小学日常的吐槽（括号里那句往往是笑点）。
3. **打就是打**——写得爽（打飞/揍翻/爆击），剧情上包装成"把愚昧打出脑壳"，但动词要有冲击力，别软。
4. **代入**——能用 {playerName} 就用，让玩的人是主角。
5. **短**——卡片/飘字一行能读完，别堆词。
